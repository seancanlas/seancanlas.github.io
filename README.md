# Sean Canlas — Personal Website

Personal site for Sean Canlas, a software engineer in Canada. Static Astro site with two React islands and a small design system.

## Stack

- **Framework**: Astro 7 (static output)
- **UI islands**: React 18, TypeScript
- **Styling**: Plain CSS with custom properties, responsive layouts, and reduced-motion support; no Tailwind
- **Components**: React Hook Form, Zod, Lucide; native HTML disclosures for project details
- **Build tooling**: Vite 8, Astro Check, ESLint 9, Prettier
- **Typography**: Public Sans, served through Google Fonts
- **Deployment**: GitHub Actions → GitHub Pages

## Development

Use Node.js 24 (matching CI) and npm.

```bash
npm install
npm run dev        # http://localhost:4321
npm run check      # Astro + TypeScript diagnostics
npm run lint
npm run build
npm run preview
```

## Structure

```
src/
├── assets/                 # Source images processed by astro:assets
├── components/
│   ├── contact/            # Contact form island
│   ├── layout/             # Header, footer, theme and language controls
│   ├── portfolio/          # Project showcase island
│   ├── sections/           # Hero and background sections
│   └── ui/                 # SVG icons
├── i18n/                   # EN/FR copy and translation helpers
├── layouts/                # HTML shell and shared home page layout
├── lib/                    # Project data, theme store, utilities
├── pages/                  # /, /fr/, 404
├── scripts/                # Header, mobile menu, scroll spy
└── styles/                 # Plain CSS, design tokens, and animations
```

## Content

- **Copy**: `src/i18n/translations.ts` (English and French), with section-specific bilingual copy in the hero, portfolio, and background components.
- **Projects**: `src/lib/constants.ts` (stack, screenshots, links).
- **Hero image**: `src/assets/profile.jpg` (full portrait; responsive 360–960px WebP variants generated by Astro at quality 80).

## Features

- English and French pages rendered as static HTML.
- Persistent light/dark theme with system preference detection.
- React screenshot galleries and native expandable engineering details. MapleLineCards includes its TradingCardGames.ca variant in the same project, with desktop light/dark WebP captures that follow the portfolio theme.
- Contact form validated with React Hook Form and Zod, submitted to Formspree.
- Responsive navigation, keyboard focus styles, and reduced-motion support.
- CSS animations and small TypeScript scripts; no animation framework.

## Routes

- `/` — English
- `/fr/` — French
- `/404.html` — not found page

Both locales share `src/layouts/HomePage.astro`. Language links point at real routes, not hash fragments.

## Deployment

Pushes to `main` run install, `astro check`, lint, and build, then publish `dist/` to GitHub Pages. The custom domain is set by `public/CNAME` (`seancanlas.com`). `public/robots.txt` and `public/sitemap.xml` are served as static files.
